# 江苏招标项目爬虫

推荐从 PowerShell 运行：

```powershell
cd "D:\工程投标智能决策系统\模块1\项目数据爬虫"
python -m pip install -r requirements.txt
python ".\江苏\crawl_remaining.py" --pages 5
```

参数说明：

- `--pages 5`：从最新公告开始采集5页，每页约20条。
- `--refresh-list`：列表页缓存失效或网站更新时重新下载列表。
- `--refresh-details`：强制重新下载详情页。
- `--reparse-cached`：解析规则修改后，重新解析本地详情缓存，但不重复访问网站。
- `--include-unknown-deadline`：保留未成功解析投标截止时间的公告；默认不保留。

程序默认只输出尚未截止的项目，结果位于：

- `数据\clean\projects.json`
- `数据\clean\projects.csv`
- `数据\rejected\rejected_projects.json`

详情页会缓存到 `数据\raw\江苏`，程序中断后再次执行会跳过已完成记录。建议每次采集5至20页，并保持默认请求间隔，不要一次遍历网站全部历史页面。

公告没有公开的控制价、暂列金额等字段会保持为空，不会补造数值。项目评级、责任人和竞争对手属于企业内部数据，本爬虫不会从公告中虚构。

## 近三年历史公告（无人值守）

运行根目录下的 `启动近三年历史采集.ps1`。历史任务会：

- 按公告日期向前回溯三年；
- 每完成一页即保存原始网页、解析结果和断点；
- 每页自动同步到 MySQL，软件端随后可查询；
- 网络中断、关机或程序异常后，重新运行脚本会从断点继续；
- 历史项目包含已经开标或截止的公告，首页默认“未开标机会”不会因此被历史数据淹没。

进度文件：`数据\clean\history_checkpoint.json`

运行日志：`日志\近三年历史采集.log`

## 手动采集近一年项目

双击或从 PowerShell 运行 `手动爬取近一年项目.ps1`。该窗口会实时显示页数、项目名称和数据库同步结果；可以随时按 `Ctrl+C` 停止，再次运行会从断点继续。

字段缺失不会直接删除项目：只有项目名称、来源地址及可用于去重的源站ID均无法确认时才拒绝入库。工程类型、业主单位、开标日期或造价字段未公开时保留为空，并标记为 `PARTIAL`，等待后续公告或人工补充。
