1.招标条件
    本招标项目丹阳市人民医院内科病房楼修缮改造项目已由丹阳市行政审批局(项目审批、核准或备案机关名称)以丹行审核[2023]17号 (批文名称及编号)批准建设，招标人为 丹阳市人民医院，建设资金来自企业投资。项目已具备招标条件，现对该项目的监理进行公开招标。

江苏正德建设管理有限公司（招标代理机构名称）受招标人的委托具体负责本工程的招标事宜。
3.工程概况与招标范围
3.1 工程地点：丹阳市人民医院内科病房楼
3.2 工程规模：改造总建筑面积 23543平方米，建设内容包括内科病房楼（既有建筑改造）、内科病房楼（装饰）、内科病房楼（智能化）、内科病房楼（医用气体）工程施工及相关服务设施建设。
3.3 监理服务期：
3.4 监理合同估算价：258.48万元
3.5 本招标工程共分1个标段，标段划分及相应招标范围如下：

5.评标办法
    本工程采用“综合评估法”的评标办法；本评标办法总分100分，其中投标报价（ 100-监理方案-项目监理机构分-拟投入现场的设备、检测仪器-类似工程业绩分-奖项分-投标人市场信用评价分，≥34分）、监理方案（18分）、项目监理机构（26分）、拟投入现场的设备、检测仪器（3分）、类似工程业绩（7.5分，其中企业3分，总监4.5分）、奖项（1.5分）、投标人市场信用评价（10分）。
5.1 投标报价（34分）
   方法一：费率下浮法；
    评标基准价=Px ( 1-K )
    投标报价分值计算方法：
        评标价等于评标基准价的得基本分（24分）。评标价相对评标基准价每上偏离1%，扣0.5分， 扣完为止；评标价相对评标基准价每下偏离1%，加0.5分，最多加10分。偏离不足1%的，按照插入法计算得分。
   说明：
    1.评标价是指经澄清、补正和修正算术计算错误的投标报价。
    2.有效投标文件是指未被评标委员会判定为无效标的投标文件。
    3.本标段施工监理服务标准收费P=258.48元。
    4.K值取值范围为30%~32%（招标人确定数值）。
    5.特殊情形下，评标基准价调整方式：
    评标结束后，除确认存在计算错误外，评标基准价不因招投标当事人异议、投诉、复评以及其它任何情形而改变；

    本工程采用“综合评估法”的评标办法；本评标办法总分100分，其中投标报价（ 100-监理方案-项目监理机构分-拟投入现场的设备、检测仪器-类似工程业绩分-奖项分-投标人市场信用评价分，≥34分）、监理方案（18分）、项目监理机构（26分）、拟投入现场的设备、检测仪器（3分）、类似工程业绩（7.5分，其中企业3分，总监4.5分）、奖项（1.5分）、投标人市场信用评价（10分）。
5.1 投标报价（34分）
   方法一：费率下浮法；
    评标基准价=Px ( 1-K )
    投标报价分值计算方法：
        评标价等于评标基准价的得基本分（24分）。评标价相对评标基准价每上偏离1%，扣0.5分， 扣完为止；评标价相对评标基准价每下偏离1%，加0.5分，最多加10分。偏离不足1%的，按照插入法计算得分。
   说明：
    1.评标价是指经澄清、补正和修正算术计算错误的投标报价。
    2.有效投标文件是指未被评标委员会判定为无效标的投标文件。
    3.本标段施工监理服务标准收费P=258.48元。
    4.K值取值范围为30%~32%（招标人确定数值）。
    5.特殊情形下，评标基准价调整方式：
    评标结束后，除确认存在计算错误外，评标基准价不因招投标当事人异议、投诉、复评以及其它任何情形而改变；
