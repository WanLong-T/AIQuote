# 模块3：投标结果与复盘分析

本目录由模块3负责人 田万龙 独立维护。

- `frontend/Module3Page.vue`：投标人报价导入、分项评分、差距分析、原因复盘、整改跟踪和知识更新审批页面。
- `backend/result-domain.mjs`：报价指标、比较口径、评分差距及复盘摘要领域逻辑。
- `backend/result-domain.test.mjs`：领域逻辑自动化测试。

模块接口统一使用 `/api/results/...` 命名空间。不要直接修改模块1、2、4的页面。

## 数据保护约定

- 每次保存均在 `bid_result_versions` 中创建新的事实版本，不覆盖或删除旧版本。
- 官方记录、公司判断、AI建议分别标识来源，AI输出不能替代正式记录。
- 模板、成本参数和经验规则只能提交更新申请，经审核后才可进入受控更新流程。
- 跨投标人比较必须同时指定标段、轮次、税费口径和费用范围。
